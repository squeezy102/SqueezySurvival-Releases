# SqueezySurvival

A single-player survival strategy game. You wake up stranded on a beach on a large island. Every action costs time, and everything you find opens new possibilities.

> Early development build. Expect missing features, rough edges and changes between versions.

## Download and play (Windows)

1. Open the [latest release](https://github.com/squeezy102/SqueezySurvival-Releases/releases/latest).
2. Under **Assets**, download the file ending in **`Setup.exe`**.
3. Run it. The game installs for your user account (no administrator rights needed), adds a desktop shortcut, and starts.
4. From then on, launch the game from the **SqueezySurvival** desktop shortcut.

### "Windows protected your PC"

The game is not code-signed, so Windows SmartScreen shows this warning the first time. Click **More info**, then **Run anyway**. This only happens on first install.

## Updating

The game checks for new versions when it starts. When one is available, click **Update** in the game. It downloads the new version and restarts. You never need to download from this page again.

## Requirements

- Windows 10 or 11, 64-bit.
- No other software required.

## Uninstalling

**Settings > Apps > Installed apps > SqueezySurvival > Uninstall.**
